This repository contains the code for the paper **Exploiting Spatial-Spectral Correlations in Semantic-Aware Sequences for Spectral Super-Resolution**.

For environment setup instructions, see [requirements/note.md](requirements/note.md).

Use [eval_cave.py](eval_cave.py) and [eval_harvard.py](eval_harvard.py) to evaluate the provided checkpoints on the CAVE and Harvard datasets.
